# Code of conduct

## Our pledge

We want this project to be a place where people can report bugs, suggest ideas, and contribute code without harassment or hostility. We welcome contributors regardless of experience, identity, background, or game knowledge.

## Expected behavior

- Be direct and respectful. Critique the work, not the person.
- Assume good intent, but ask when something is unclear.
- Keep discussion on topic and useful to the project.
- Accept that maintainers may reject a change to keep the project focused.
- Respect privacy. Do not post API keys, personal data, or private messages.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, doxxing, spam, and deliberate disruption are not acceptable in issues, pull requests, discussions, or other project spaces.

## Enforcement

Maintainers may edit or remove content and may warn, temporarily block, or permanently ban accounts for behavior that violates this code. Enforcement decisions should be proportionate and focused on keeping the project usable.

Report a problem through the repository's private security advisory link if the report is sensitive, or contact a maintainer through GitHub. Do not use a public issue for a personal dispute.

## Scope

This code applies in project spaces and when someone represents the project in public.
